# My Beginning with Python

Welcome to my Python learning repository! This is a public log of my journey mastering Python, from core fundamentals to building standalone projects and applications.

## Repository Structure

* **/fundamentals:** Basic syntax, data structures, and core Python concepts.
* **/coursework:** Exercises and challenges from structured courses (e.g., freeCodeCamp).
* **/projects:** Small applications, automation scripts, and problem solvers.
* **/notes:** Markdown notes on computer science concepts, algorithms, and technical reading.

## Getting Started

To run these scripts locally on your machine:

```bash
git clone [https://github.com/smaurya-dev/Beginning-with-Python.git](https://github.com/smaurya-dev/Beginning-with-Python.git)
cd Beginning-with-Python
python projects/script_name.py
