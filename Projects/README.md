# Projects

This directory contains small, standalone applications and utility scripts where knowledge is applied to solve actual problems.

## Project Types

* **Data Parsers:** Scripts designed to fetch, process, and analyze data using libraries like `requests` and `pandas`.
* **Terminal Utilities:** Command-line interfaces (CLIs) for automating local tasks or solving complex mathematical mechanics.
* **App Backends:** Core Python logic, data processing, and file management scripts built to support larger graphical applications.
